# دكّان

نظام بسيط لبقالة صغيرة: بيع سريع، مخزون مع تنبيه النقص، استلام بضاعة، تقارير، ونسخ احتياطي.
واجهة عربية بالكامل (من اليمين لليسار)، وتعمل بدون إنترنت، والبيانات تُحفظ محليًا في المتصفح

## التشغيل (من GitHub Codespaces)

```bash
./run.sh
```

أول مرة يحمّل Flutter ويبني الموقع، وياخذ عدة دقائق. بعدها افتح المنفذ 8080 من تبويب Ports.

## الأقسام

- بيع: أصناف على شكل أزرار، فاتورة جانبية، وحساب الباقي للعميل.
- المخزون: إضافة وتعديل وجرد الأصناف.
- استلام بضاعة: تسجيل الداخل من المورّدين وتحديث سعر الشراء.
- التقارير: اليوم و7 أيام والشهر، الأكثر مبيعًا، والأصناف التي تحتاج طلب.
- الإعدادات: اسم المحل، نسخ احتياطي واستعادة.
